# Pizza Yard Sunday Breakfast

Add these files to the same `yardPizza1` GitHub Pages repository:
- `index.html` (replacement)
- `breakfast-banner.css`
- `breakfast.html`
- `breakfast.css`
- `breakfast.js`
- `dashboard.html` (replacement)
- `dashboard.css` (replacement)
- `dashboard.js` (replacement)

Run `sunday-breakfast.sql` once in the existing Pizza Yard Supabase project.

The breakfast page uses the existing Pizza Yard Supabase project and the existing staff dashboard login. Breakfast orders are weekly by `target_sunday`; old orders remain in the database and the dashboard only shows the current Sunday cycle.
