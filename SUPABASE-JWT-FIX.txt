Pizza Yard — Supabase JWT + Edge API Fix

Customer pages now use a non-persistent anonymous Supabase client so stale staff
Auth sessions are never attached to public customer requests.

Staff pages use the pizza-yard-staff-api Edge Function for database operations.
The function verifies the user's JWT with Supabase JWKS, tolerates up to 5 minutes
of clock skew, checks public.staff_users, and uses the server-only secret key for
PostgREST operations.

Staff operations covered:
- pizza_orders
- breakfast_orders
- pizza_topping_availability
- pizza_reviews
- inventory_items
- inventory_stock_events
- inventory_daily_counts
- verify_reward_code RPC

The browser contains only the publishable key. Never put a secret/service-role key
in the browser.
